# Healthcare-Predictive-Analytics-using-Microsoft-Excel
Healthcare Predictive Analytics using Microsoft Excel to forecast drug demand based on historical data and flu cases through regression analysis, model evaluation, and data visualization.

📌 Project Overview

This project focuses on healthcare predictive analytics using historical drug demand data. The objective is to develop a basic predictive model to forecast pharmaceutical demand by analyzing historical demand patterns and flu case data.

Microsoft Excel was used to organize the dataset, perform regression analysis, generate predicted demand values, evaluate model performance, and visualize actual versus predicted demand.

🎯 Objectives

- Analyze historical pharmaceutical demand data.
- Explore the relationship between flu cases and drug demand.
- Develop a predictive model using regression analysis.
- Forecast drug demand for 2025 using historical data.
- Evaluate prediction errors using statistical metrics.
- Visualize actual and predicted demand to understand model performance.

🛠️ Tools and Technologies

- Microsoft Excel
- Historical healthcare and pharmaceutical data
- Excel Data Analysis ToolPak
- Regression Analysis
- Statistical Error Metrics
- Charts and Data Visualization

📂 Dataset Description

The dataset contains historical monthly information related to pharmaceutical demand.

The main variables used in the analysis include:

- Month Number: Sequential month identifier.
- Flu Cases: Recorded flu cases for the corresponding month.
- Drug Demand: Historical pharmaceutical demand.
- Predicted Demand: Demand estimated by the regression model.

The historical data was used to develop the model, while the 2025 data was used for forecasting and comparison.

⚙️ Project Workflow

1. Data Preparation

Organized the historical drug demand dataset in Microsoft Excel and identified the relevant variables for predictive analysis.

2. Exploratory Data Analysis

Examined historical drug demand and flu case patterns to understand how demand varied over time.

3. Regression Modeling

Applied multiple linear regression analysis in Excel using Month Number and Flu Cases as independent variables and Drug Demand as the dependent variable.

The regression model was designed to estimate drug demand based on the selected input variables.

4. Demand Prediction

Used the regression output to calculate predicted demand values and compared the predictions with the corresponding actual demand values.

5. Model Evaluation

Evaluated the model using the following metrics:

- MAE (Mean Absolute Error): Measures the average absolute difference between actual and predicted values.
- RMSE (Root Mean Squared Error): Measures prediction error while giving greater weight to larger errors.
- MAPE (Mean Absolute Percentage Error): Measures prediction error as a percentage of actual values.

6. Data Visualization

Created charts in Excel to visualize historical drug demand and compare actual versus predicted demand for 2025.
